# 🚘 Nuvio for Android Automotive

An independent Nuvio fork focused on Android Automotive OS (AAOS), with the **Polestar 3** as its target vehicle. This page highlights what is different in this fork.

## What’s different

- 🖥️ **Made for the car display** — larger text and icons make screens easier to read at a glance.
- 👆 **More comfortable controls** — larger navigation and back buttons, player controls, and seek touch targets are designed for in-car screens.
- 🖼️ **Roomier home screen** — larger posters, clearer shelf labels, and spacing tuned for browsing. At a 1280 dp width, the home screen shows five full poster cards with the next card peeking in.
- 🔎 **Clearer search and navigation** — larger search field and labels, with Discover limited to four columns.
- 🔐 **Phone-based sign-in** — device-code login is designed for the head unit, with a trusted custom-server option including `api.nuvio.tv` if needed.
- 📱 **Fork-specific app identity** — Android package name: `com.JF_Nuvio`.
